##  Objetivo do Projeto

Este projeto foi desenvolvido como parte do Projeto Integrador do segundo semestre do curso de Análise e Desenvolvimento de Sistemas (ADS) do SENAI Jandira. O objetivo foi aplicar, na prática, os conhecimentos adquiridos ao longo do semestre nas áreas de Front-End, Back-End, Banco de Dados e Gestão de Projetos.

A solução consiste em um site de marmitas fitness, com foco na apresentação de refeições saudáveis de forma prática e intuitiva, permitindo a visualização de produtos e suas informações nutricionais.
